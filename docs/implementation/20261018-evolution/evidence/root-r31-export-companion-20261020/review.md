# Exportación R31: companion de compatibilidad

Los cuatro comandos pasan108 ejecuciones, con49 nombres de caso distintos;
los solapamientos se declaran y no se presentan como108 casos únicos.
Se ejecutan el API y el consumidor actuales con dobles VM de DOM, Blob,
Storage, cookie y Web Lock. No es una prueba de navegador nativo o servidor.

El companion conserva las aserciones originales de negocio. La obligación
antigua de persistir credenciales cambia por el epoch no secreto y se añaden
comprobaciones de ausencia de credenciales persistidas. El observador legado
lee RAM; el cambio de actor se representa mediante una invalidación externa
terminada y no mediante adopción de tokens. Los diez RAW ejecutados coinciden
con las fotografías antes/después y se conservan en el archivo privado.

El gate precede al commit del test; ambos estados se identifican por separado.
No se editaron producto, helpers compartidos ni fuentes históricas. La revisión
independiente de QA pertenece a su propio sello. Sólo servicio web.
