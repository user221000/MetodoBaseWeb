El servidor8a conserva el contrato legacy sin header y ofrece la sesión de
navegador mediante cookie HttpOnly y acceso en RAM. La admisión de Origin,
header y JSON precede al lookup opcional de identidad del middleware.

Las once fases conservan sus estados y fallos: no se suman como casos únicos
ni se atribuyen retrospectivamente al commit final. El primer framing rechazaba
también la cookie CSRF independiente:24 casos con12 fallos, luego24 verdes
sin cambio de producto. Los ocho adicionales pasan; las cuatro pruebas Google
antiguas fallan también sobre las rutas previas y se conservan abiertas como
compatibilidad de fixtures, sin contarlas como aprobadas. El companion Google
actual conserva sus correcciones de origen, sujeto sintético y200/307.
