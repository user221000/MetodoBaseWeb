## Contrato nuevo

`build.py` requiere `--source-commit` con SHA completo. Comprueba la raíz efectiva y HEAD exactos, compara el índice con el árbol del commit y verifica los bytes de cada archivo contra sus blobs, sin confiar en `git status` ni las banderas assume-unchanged/skip-worktree. Inventaría los hashes físicos y vuelve a comprobarlos antes/después de pruebas, empaquetado y preparación del manifiesto. No importa `config.constantes`: lee VERSION por AST, evitando crear perfiles o interpretar variables de producto durante el import del script.

La política de checkout acepta bytes exactos, o CRLF uniforme de un blob UTF-8 LF cuando no hay `-text` ni `eol=lf`; el EOL explícito se respeta. Los binarios y blobs históricos CRLF se comparan byte a byte. No ejecuta filtros clean/smudge: rechaza `filter`, `ident`, working-tree-encoding y atributos no soportados. Lee los [atributos del commit seleccionado](https://git-scm.com/docs/git-check-attr), desactiva atributos/configuración global/sistema, hooks, fsmonitor y replace refs, y rechaza overrides activos en info/attributes, cuya precedencia está documentada por [Git](https://git-scm.com/docs/gitattributes). No altera índice, flags ni configuración del operador. Este contrato conserva Git y su almacén de objetos como herramienta/base de confianza, no resiste a un proceso hostil que sustituya todo el namespace durante la operación.

`MetodoBase.spec` analiza `main.py`, conserva PySide6 y produce onedir `dist/MetodoBase` con `_internal`. Declara fuentes, recursos gráficos y QSS como archivos individuales obtenidos de Git; no copia carpetas de configuración, módulos Python o datos personales como bloques de datos. Limpia variables `GIT_*` antes de inventariar y comprueba la raíz efectiva del worktree. La lista de extensiones y los recursos mínimos son explícitos; faltar un recurso requerido aborta. Los módulos del producto se incluyen mediante el análisis/imports de PyInstaller.

El bundle requiere ejecutable, fuentes/QSS y plugins Qt nativo/offscreen según plataforma. Un manifiesto cubre el conjunto exacto y SHA256 de cada archivo; después de un build guardaría además commit y versiones de herramientas. El ZIP incluye todo el árbol y manifiesto, con nombres POSIX bajo `MetodoBase/`. Rechaza archivos privados, bases, cachés de licencia, directorios de datos/entornos, nombres ambiguos, symlinks y junctions. Verifica también los bytes dentro del ZIP antes de publicar mediante reemplazo de un archivo temporal. Un error conserva el ZIP anterior y elimina el temporal.

La limpieza se limita a `build` y `dist` bajo la raíz seleccionada, con comprobación previa de límites/enlaces. Conserva `.spec`, `__pycache__` y archivos ajenos. Un bundle previo impide inferir éxito de una compilación nueva. Los errores del subproceso y cambios de fuente invalidan el candidato.

El hook crea QApplication, carga Inter/tema e instancia la ventana de login, luego termina antes del flujo de negocio de `main.py`; no activa licencias ni concede sesión. No usa HTTP, `--help` o `--no-browser` como señal de éxito.

Ese hook limita sockets Python y registra `os_network_isolation_verified=false`; no equivale a bloqueo de red OS para código nativo Qt. ## Revisión independiente final de procedencia

QA encontró dos caminos adicionales en abfee196: bytes UTF-8 válidos con controles binarios y un CR aislado podían aceptar un checkout modificado como si fuera el commit. Coordinación corrigió ambos sin modificar los canarios independientes. Controles ASCII distintos de TAB/CR/LF, DEL y CR fuera de un par CRLF ahora exigen bytes exactos, incluso con atributos de texto. ESC también exige exactitud de forma conservadora aunque Git lo clasifique como texto; los blobs históricos CRLF conservan su comparación exacta.

La primera expectativa de autor para ESC decía `i/-text`, pero Git informó `i/lf`; se conserva ese fallo de la prueba nueva y sólo se corrige su expectativa. No se cambió el criterio del canario independiente. Los cuatro casos portables de autor pasaron después. QA ejecutó 94 casos finales en 22.85 s, sin fallos, errores ni omisiones: 85 mantenidos, sus ocho canarios originales y uno nuevo para CR aislado. Las 27 fuentes, índice, flags y configuración permanecieron estables. Evidencia del checkout coordinador: `evidence/desktop-qa-review-abfee196/desktop-provenance-final-independent-source.json`; los dos rojos anteriores permanecen separados.

Este pase acepta la receta y la comparación de fuentes. Aún falta construir desde el commit integrado exacto y verificar el bundle, ZIP, diagnóstico empacado e instalador por separado.
