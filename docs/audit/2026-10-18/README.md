# Auditoría y roadmap de MetodoBase

Revisión del 18 de octubre de 2026 sobre la copia local, GitHub y Railway `joyful-quietude`. La aplicación tiene una base aprovechable; cobros, permisos, migraciones, aislamiento y continuidad del socio requieren atención antes de ampliar captación.

1. [Informe integral](INFORME_INTEGRAL.md): conclusión, alcance, pruebas y problemas consolidados.
2. [Roadmap priorizado](ROADMAP_PRIORIZADO.md): 35 elementos, ventanas de 90 días, dependencias, responsables y aceptación.
3. [Arquitectura y documentación](ARQUITECTURA_Y_DOCUMENTACION.md): evolución modular, vínculo gimnasio y socio y documentación de código.
4. [Operación y seguridad](OPERACION_Y_SEGURIDAD.md): evidencia real de Railway/PostgreSQL y controles a verificar.
5. [Backend y seguridad](backend/INFORME_BACKEND.md): escenarios reproducidos, catálogo PostgreSQL y dependencias.
6. [QA y pruebas](qa/INFORME_QA.md): comandos, resultados, cobertura, CI y migraciones.
7. [UX y producto](ux/INFORME_UX.md): recorridos, capturas, accesibilidad y oportunidades para dueño y socio.

Los archivos en `evidence/`, `backend/`, `qa/` y `ux/` contienen resultados saneados y herramientas de reproducción. Las capturas autenticadas son de cuentas sintéticas locales. No se modificó código de producto ni producción, ni se publicaron estos informes en GitHub. Los resultados de las distintas disciplinas se solapan; no deben sumarse como vulnerabilidades únicas.
